# Public Examples

This folder is reserved for sanitized demo artifacts only. Do not copy production scripts, logs, diagrams, device inventories, tenant IDs, app IDs, IP addresses, or customer/job data into this public repo.

Current examples live in `../toolkit`:
- Intune Win32 package pattern with fake domains and fake app metadata.
- Employee resource deployment for bookmarks, shortcuts, trusted sites, and self-service links.
- Network share mapping with stable DNS names and generated sample paths.
- Endpoint posture JSON schema with generated sample devices.
- Health evidence card pattern with fake deployment data.
- Network/endpoint handoff template for joint changes.
