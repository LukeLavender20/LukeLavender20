# Managed Software Catalog

This is a simple public-safe pattern for tracking what software should exist on managed devices.

## Why It Matters

Enterprises need to know more than "the app was published." They need to know the intended version, assignment, detection method, update source, owner, and rollback path.

## Fields I Track

- Package ID.
- Display name.
- Owner.
- Platform.
- Assignment.
- Install command.
- Detection command.
- Latest version.
- Update source.
- Rollback path.
- Evidence location.
- Risk level.
